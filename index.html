Halcyon Backup

A personal backup tool. Not a public service.

Halcyon Backup copies one small, encrypted backup file per day from its owner's home server to the owner's own Google Drive, so that a copy survives if the server fails.

  • It is used by one person, its owner, for their own data.
  • It can only see files it created itself in Google Drive (the drive.file permission), never anything else stored there.
  • Backups are encrypted on the owner's server before they are uploaded.
