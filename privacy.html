Privacy policy

Last updated: 16 November 2026

Halcyon Backup is a personal tool run by its owner for their own backups. It is not offered to anyone else.

What it accesses

With the Google permission https://www.googleapis.com/auth/drive.file, Halcyon Backup can create, read and delete only the files it uploaded itself to the owner's Google Drive. It cannot see, open or change any other file in that Drive.

What it stores

One encrypted backup file per day from the owner's own home server, kept for seven days. The files are encrypted before they leave the server; Google stores them, but cannot read their contents.

Sharing

No data is sold, shared with or shown to anyone. Nothing is used for advertising, analytics or profiling. No other people's data is collected.

Google API Services

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Removing access

The owner can revoke access at any time in their Google Account under Security → Third-party apps and services, and delete the backup files from Google Drive.
